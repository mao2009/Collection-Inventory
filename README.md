## 運用方針

- **一覧**：このREADMEから各Issueへ移動。GitHub Issuesの検索・ラベルでも絞り込み可能。
- **個別**：1所持個体につき1 Issue。複数本あれば別Issueにする。
- **登録**：Issues → New issue → 「コレクション登録」フォーム。
- **状態**：IssueのOpen/Closedは所有・非所有を意味しない。所持状態は本文に記録する。
- **画像**：PS2作品は型番で [xlenore/ps2-covers](https://github.com/xlenore/ps2-covers) の画像を外部参照可能。現物写真は別途Issueに添付する。
- **注意**：購入金額、保管場所、シリアル番号、現物写真などの機微情報はPublic化前に確認する。
