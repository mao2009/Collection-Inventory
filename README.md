## 新規登録・運用

- [新しい所持品を登録する](../../issues/new/choose)（「コレクション登録」フォーム）
- [登録済みIssue一覧](../../issues)
- 1つの所持個体につき1 Issue。重複所持は別Issueで記録します。
- ケース・説明書・ディスク・動作確認・購入価格などは個別Issueで管理します。
- IssueのOpen/Closedは所有・非所有を意味しません。
- 一覧の行は現在手動で更新しています。新規登録での自動反映は未実装です。
- Privateで運用し、公開前には購入情報や個人情報を確認してください。
